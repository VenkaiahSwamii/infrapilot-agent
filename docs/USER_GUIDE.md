# 📖 InfraPilot Enterprise v1.0 User Guide

Welcome to the **InfraPilot Enterprise v1.0 User Guide**. InfraPilot is an all-in-one infrastructure monitoring, multi-cloud observability, AI incident intelligence, and auto-remediation platform.

---

## 🚀 Key Modules & Navigation

### 1. Unified Dashboard
- Real-time KPI summary cards (Host machines, CPU/Memory utilization, active containers, K8s pods, pending alerts).
- Live WebSocket telemetry updates and interactive historical time-series charts.

### 2. Multi-Cloud Observability (`/cloud`)
- Monitor AWS, Azure, and Google Cloud Platform (GCP) from a single pane of glass.
- Track virtual machines, EKS/AKS/GKE clusters, database instances, FinOps cost analysis, and CSPM security posture findings.

### 3. Docker & Kubernetes Observability
- Container metrics, container log streaming, container lifecycle control (start, stop, restart).
- K8s cluster status, node pool health, pod deployment rollouts, and event streaming.

### 4. Autonomous AIOps & Incident Intelligence (`/aiops`)
- RAG-based AI assistant for infrastructure troubleshooting and root cause analysis.
- Anomaly detection engine and predictive metric forecasting.

### 5. Enterprise Automation & Auto-Remediation (`/automation`)
- Rule-based auto-remediation workflows (e.g. IF High CPU -> Restart Service).
- Pre-approved 1-Click operational runbooks library (Restart Nginx, Clear Cache, Vacuum Logs, Restart DB).
- Human-in-the-loop pending approval requests queue.

### 6. Analytics & Executive Reports (`/analytics`)
- Trend analysis, capacity forecasting, SLA compliance reporting (99.99%), and automated PDF/CSV report exports.
