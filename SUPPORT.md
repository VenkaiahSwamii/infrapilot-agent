## 🚀 Getting Help

### 1. Search Existing Issues & Discussions
- Search [GitHub Issues](https://github.com/venkaiswami/infrapilot-enterprise/issues) for similar problems
- Check [GitHub Discussions](https://github.com/venkaiswami/infrapilot-enterprise/discussions) for community Q&A
- Review [Troubleshooting Guide](docs/troubleshooting.md) for common solutions

### 2. Ask in GitHub Discussions
For questions, best practices, or community support:
- **[GitHub Discussions - Q&A](https://github.com/venkaiswami/infrapilot-enterprise/discussions)** - Ask questions
- **[GitHub Discussions - Ideas](https://github.com/venkaiswami/infrapilot-enterprise/discussions)** - Share feature ideas

### 3. Report a Bug
If you've found a bug:
- Check **[existing bug reports](https://github.com/venkaiswami/infrapilot-enterprise/issues?q=is%3Aissue+is%3Aopen+label%3Abug)**
- If not reported, **[open a new bug report](https://github.com/venkaiswami/infrapilot-enterprise/issues/new?template=bug_report.md)**

### 4. Request a Feature
For feature requests or enhancements:
- Check **[existing feature requests](https://github.com/venkaiswami/infrapilot-enterprise/issues?q=is%3Aissue+is%3Aopen+label%3Aenhancement)**
- If not requested, **[open a feature request](https://github.com/venkaiswami/infrapilot-enterprise/issues/new?template=feature_request.md)**

### 5. Security Issues
**DO NOT** open public issues for security vulnerabilities.

Report security issues privately at: **[venkaiswami@pm.me](mailto:venkaiswami@pm.me)**

See [Security Policy](docs/security.md) for more details.

## 📝 Before You Ask

To help us help you faster, please include:

**For Bug Reports:**
- OS and version (Ubuntu 22.04, Windows 11, etc.)
- Deployment method (Docker Compose, Kubernetes, manual)
- Component affected (backend, frontend, agent)
- Relevant logs and error messages
- Steps to reproduce

**For Questions:**
- What you're trying to achieve
- What you've already tried
- Relevant configuration (redact secrets/tokens)
- Error messages or screenshots
