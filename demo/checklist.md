# Pre-Recording Checklist

## Environment

- [ ] Fresh demo data seeded (3-5 machines, mixed online/offline states)
- [ ] At least one active alert and one resolved alert in history
- [ ] At least one machine with running Docker containers (2-3 containers, mixed states)
- [ ] A Kubernetes cluster (kind/minikube is fine) with a couple of pods for the K8s tab
- [ ] Sample files in the remote file manager's target directory
- [ ] Historical metrics populated (run agents for at least 15-20 minutes beforehand so charts aren't empty)

## Recording Setup

- [ ] Screen resolution set to 1920x1080
- [ ] Browser zoom at 100%, bookmarks bar hidden, single relevant tab open
- [ ] Do Not Disturb / notifications off
- [ ] Microphone tested, background noise minimized
- [ ] Recording software configured (OBS Studio / Loom) at 1080p, 30-60fps
- [ ] Terminal font size increased for readability

## Post-Production

- [ ] Trim dead air at start/end
- [ ] Add captions/subtitles if possible (improves accessibility & watch time)
- [ ] Add title card with project name + your name
- [ ] Add end card with GitHub repo link, portfolio link, and contact info
- [ ] Export at 1080p H.264, upload to YouTube (unlisted or public) or Loom
- [ ] Update README.md, docs/portfolio.md, and website/index.html with the final video link
