# Demo Video

This folder contains the script, shot list, and recording checklist for the InfraPilot Enterprise walkthrough video referenced in the root [README.md](../README.md).

## Files

| File | Purpose |
|------|---------|
| `script.md` | Full narration script and shot-by-shot outline (10-15 min) |
| `checklist.md` | Pre-recording setup checklist |

## Publishing

1. Record following `script.md`.
2. Upload to YouTube (unlisted or public) or Loom.
3. Replace the placeholder thumbnail/link in the root `README.md` "Demo Video" section with your real video URL and thumbnail:

```markdown
[![InfraPilot Enterprise Demo](https://img.youtube.com/vi/YOUR_VIDEO_ID/0.jpg)](https://youtu.be/YOUR_VIDEO_ID)
```

4. Also update `docs/portfolio.md` and `website/index.html` with the same link.
