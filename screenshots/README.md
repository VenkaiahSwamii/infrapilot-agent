# Screenshots

This directory contains screenshots and demo assets for the InfraPilot Enterprise repository.

## Required Screenshots

Place the following screenshots in this directory for a professional README:

### 1. Dashboard Overview (`dashboard.png`)
- **Content:** Full dashboard with KPI cards, live charts, and machine list
- **Resolution:** 1920x1080
- **Tips:** Show at least 3-5 machines, mixed online/offline states, active alerts

### 2. Login Page (`login.png`)
- **Content:** Clean login form with branding
- **Resolution:** 1280x720 or wider

### 3. Machine Details (`machine-details.png`)
- **Content:** Single machine view with Overview tab active
- **Resolution:** 1920x1080

### 4. Docker Monitoring (`docker-tab.png`)
- **Content:** Docker tab showing running containers with metrics
- **Resolution:** 1920x1080

### 5. Kubernetes Monitoring (`kubernetes-tab.png`)
- **Content:** Kubernetes tab with pods/nodes view
- **Resolution:** 1920x1080

### 6. Terminal (`terminal.png`)
- **Content:** Remote terminal with active command
- **Resolution:** 1920x1080

### 7. File Manager (`file-manager.png`)
- **Content:** File browser with directory listing
- **Resolution:** 1920x1080

### 8. Alerts Page (`alerts.png`)
- **Content:** Alerts list with severity badges
- **Resolution:** 1920x1080

### 9. Reports (`reports.png`)
- **Content:** Reports page with generation options
