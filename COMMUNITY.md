## 🚀 Contributing

We welcome contributions from everyone! See [CONTRIBUTING.md](CONTRIBUTING.md) for detailed guidelines.

### Ways to Contribute

#### 1. 🐛 Report Bugs

Help us improve by reporting bugs:
- Check existing [issues](https://github.com/venkaiswami/infrapilot-enterprise/issues) first
- Use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md)
- Include steps to reproduce, expected vs actual behavior

#### 2. 💡 Suggest Features

Have an idea? Share it!
- Check [feature requests](https://github.com/venkaiswami/infrapilot-enterprise/labels/enhancement)
- Use the [feature request template](.github/ISSUE_TEMPLATE/feature_request.md)
- Describe the problem, not just the solution

#### 3. 📝 Improve Documentation

Documentation is critical:
- Fix typos and clarify confusing sections
- Add examples and tutorials
- Translate documentation
- Update outdated information

#### 4. 🔌 Build Plugins

Extend InfraPilot with plugins:
- Cloud providers: AWS, Azure, GCP, VMware
- Notifications: Slack, Teams, Discord, Telegram
- Custom monitoring scripts
- See [Plugin SDK](docs/plugin-sdk.md)

#### 5. 💻 Submit Code

Fix bugs or implement features:
- Look for [`good first issue`](https://github.com/venkaiswami/infrapilot-enterprise/labels/good%20first%20issue) labels
- Follow our [contribution guide](CONTRIBUTING.md)
- Submit pull requests

#### 6. 🧪 Write Tests

Improve test coverage:
- Backend tests (Go)
- Frontend tests (Jest)
- Integration tests
- See [testing guide](CONTRIBUTING.md#testing)

#### 7. 🎨 Design & UX

Improve the interface:
- UI/UX enhancements
- Accessibility improvements
- New dashboard widgets
- Themes and styling

#### 8. 🌐 Translate

Help make InfraPilot accessible:
- Translate documentation
- Localize the UI
- Make it accessible to non-English speakers

## 🤔 FAQ

**Q: How can I get involved?**
A: Start by starring the repo, reading documentation, and joining discussions. Look for `good first issue` labels.

**Q: Do I need to be an expert to contribute?**
A: No! We welcome all skill levels. Documentation, testing, and bug reports are valuable contributions.

**Q: Can I use InfraPilot in my company?**
A: Yes! InfraPilot is MIT-licensed, free for commercial use.

**Q: How do I report a security vulnerability?**
A: See [SECURITY.md](docs/security.md) for responsible disclosure guidelines.

**Q: Is there a mobile app?**
A: Not yet, but it's on the roadmap! Check back soon or contribute to building one.

**Q: Can I build plugins?**
A: Absolutely! See the [Plugin SDK](docs/plugin-sdk.md) to get started.

**Q: How do I request a feature?**
A: Use the [feature request template](.github/ISSUE_TEMPLATE/feature_request.md).

**Q: Where can I get help?**
A: GitHub Discussions, GitHub Issues, or email venkaiswami@pm.me
